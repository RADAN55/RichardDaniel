# Richard A. Daniel — personal site

Single-file site for GitHub Pages. No build step.

## Publish
1. Create a repo (e.g. `richard-daniel`) on github.com/RADAN55.
2. Upload `index.html` to the repo root.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)` → Save.
4. Site appears at `https://radan55.github.io/<repo-name>/` within a minute or two.

The headshot is embedded in the HTML, so there is nothing else to upload.
